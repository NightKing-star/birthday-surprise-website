# Birthday website

Open `index.html` in any modern browser. It works without a server or internet connection, except that the optional decorative font loads when a connection is available.

## Make it personal

- Replace `assets/photos/photo-1.svg`, `photo-2.svg`, and `photo-3.svg` with photos. Keep the filenames, or update the three `src` values in `index.html`.
- Edit the note inside the `<article class="letter">` in `index.html`.
- The music button plays a gentle built-in looping tune only after the recipient taps it. This avoids browsers blocking automatic audio and keeps the package self-contained.

To share it, send the ZIP file. The recipient can extract it and open `index.html` in Chrome, Edge, Safari, or Firefox.
